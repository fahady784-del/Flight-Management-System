# Flight Management System

## About the Project

The Flight Management System is a C++ console-based application developed using a Binary Search Tree (BST). It manages flight records using unique Flight IDs.

The system allows users to:
- Add new flight records.
- Search for flights using Flight ID.
- Delete flight records.
- Display all flights in ascending order of Flight ID.
- Calculate Estimated Time of Arrival (ETA).
- Determine flight status (On-Time, Early, or Delayed).
- Save and load flight records using `flights.txt`.
- Count the total number of flights.

## How to Run
### Requirements
- C++ compiler (GCC/MinGW).
- Visual Studio Code or any C++ IDE.

### Compile the Program

Open the terminal in the project folder and run:
g++ FA25-BSE-158.cpp -o Flight-Management-System
